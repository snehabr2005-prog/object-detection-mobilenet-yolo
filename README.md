# Real-time Object Recognition using CNN

This project demonstrates 2 CNN approaches with live camera.

## Features
- **Mode 1: MobileNetV2** - Image Classification (Single object with confidence %)
- **Mode 2: YOLOv8** - Object Detection (Multiple objects with bounding boxes)

## How to Run
pip install opencv-python ultralytics tensorflow
python cnn_imagerec.py

## Controls
- Press `m` -> MobileNet Classification mode
- Press `y` -> YOLO Detection mode
- Press `q` -> Quit

## Results
- Sample 1 & 2: MobileNet classification
- Sample 3 & 4: YOLO detection

## Tech Stack
Python, OpenCV, TensorFlow, Ultralytics YOLOv8
